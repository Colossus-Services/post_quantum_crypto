# Test-vector provenance

Generated by `dart run tool/fetch_vectors.dart`. Files are trimmed subsets of the upstream sources below; the SHA-256 is of the full upstream file at download time.

- NIST ACVP: the first N tests per group.
- Wycheproof ML-KEM / ML-DSA (`wycheproof_mlkem_*`, `wycheproof_mldsa_*`): every test whose result is not `valid` is kept; valid tests are kept up to N per (group, flag set), so every kind of edge case is represented. The semi-expanded decapsulation sets are kept whole.
- RFC examples (`rfc*_examples.json`): every PEM block of Appendix C, with its section number and label, decoded to DER (hex). C.3 certificates are included but not used (this package has no X.509 certificate parser).
- Not used: RFC 9909 (SLH-DSA in X.509), whose only example is SLH-DSA-SHA2-128s; this package implements the SHAKE parameter sets only.
